# 🚀 CareerGenAI — AI Career Assistant

CareerGenAI is a Generative AI-powered career guidance platform designed to help students understand their skills, identify career opportunities, discover skill gaps, and build personalized learning roadmaps.

The platform analyzes a student's education, skills, interests, career goal, and experience level to generate personalized AI-powered career guidance.

---

## ✨ Features

### 🎯 Career Recommendation
Analyzes the user's profile and provides a suitable career direction based on their target role, interests, and existing skills.

### 📊 Career Match Score
Generates a career match percentage to help users understand how closely their current profile aligns with their target career.

### 💪 Skill Gap Analysis
Identifies:

- Current technical skills
- Missing skills
- Skills that should be learned next

### 🗺️ Personalized Learning Roadmap
Generates a step-by-step learning roadmap based on the user's career goal and current experience level.

### 🚀 AI Project Recommendations
Suggests practical projects that can help students build experience and strengthen their portfolios.

### 📄 Resume Improvement
Provides AI-generated suggestions to improve the user's resume and highlight relevant technical skills and projects.

### 📈 Career Readiness Dashboard
Displays multiple readiness indicators:

- Career Match
- Technical Skills
- AI Readiness
- Overall Readiness
